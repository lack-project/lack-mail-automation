# AI Usage Info

## Primary facade

Use `MailAutomation` as the normal application entry point. Configure one
`MailClient`, durable storage, Inbox/Sent folders and a `MailAnalyzer`.
Register application actions with `scanAutomations()` when they are simple
zero-constructor classes, otherwise with `addMailAutomation()` or
`addMailActions()`.

A normal `run()` always scans Sent before Inbox. Sent is the authoritative
source for outgoing conversation history, including manually changed mail.

## Mail model

`MailAnalyzer::analyze()` returns `Content\AiMail`. The observed mail is an
AI Harness `AiContent` with ID, aliases, instructions, summary, complete
history and available attachments.

`ai_mail()`, `ai_reply()` and `ai_forward()` return
`Content\AiMailDraft`. `AiMailDraft extends AiMail` and adds
`setRecipient()`, `setSubject()`, `setText()`, `attach()`, `draft()`
and `send()`.

Draft delivery metadata is staged locally and reconciled with the Sent copy
later. The Sent scan restores draft ID, aliases and instructions. A unique
recipient+subject match permits manual body edits between draft generation and
sending.

## Routing

Declare one business action with `#[OnMailAction(condition: ..., priority: ...)]`.
The AI evaluates the complete condition against the mail conversation and
selects at most one action. Higher numeric `priority` only resolves overlap
between otherwise matching actions.

```php
#[OnMailAction(
    condition: 'The applicant approved the latest CV without requested changes.',
    priority: 100,
)]
final class ForwardApprovedCvAction
{
    public function __invoke(AiMail $mail): MailAction
    {
        $pdf = $mail->ai_query_content(
            'Select the latest CV we sent to the applicant.',
        )->first();

        return $mail->ai_forward(
            'office@example.org',
            new PromptFile(__DIR__ . '/forward.md'),
        )->setSubject('Approved CV')->attach($pdf)->send();
    }
}
```

## Standard registration

```php
$automation->scanAutomations(__DIR__ . '/actions', '*Action.php');
$automation->run();
```

Use `scanSent()` and `scanInbox()` only when the cycle must be controlled
manually.

## Specialized APIs

Tags, metadata bags, contacts, manual IMAP flags, legacy folder rules, managed
moves and filtered history remain available, but are secondary APIs rather than
the default application model.
